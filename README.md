# 投資クオンツ基盤 v1.3（分散ガード付き無料MVP）

日本株と米国株を対象に、取得時点の `close` フィールドを使って毎日自動スクリーニングするGitHub Actions用パッケージです。

## 先に結論：この版でできること

1. JPXとNasdaq Traderの公開一覧から日本・米国の上場株ユニバースを取得
2. 非公式のTradingViewスキャナーから全銘柄の価格・財務・Momentumを市場単位で一括取得
3. 公式一覧と照合し、対象外商品を除外
4. Value 25%、Quality 25%、Growth 20%、Momentum 15%、Risk 15%で相対スコア化
5. 日本・米国それぞれ上位50銘柄、計100銘柄を保存。ただし金融・海運は各最大2社、モーゲージREITは監視専用として候補から外す
6. 前回順位との差分とテーマ偏りを `daily_report.md` に出力
7. 日本時間の平日16:00に自動更新

## 重要な制約

- 株価・財務・騰落率は非公式かつ未公開仕様のTradingViewスキャナーから取得します。仕様変更で停止する可能性があります。
- `close` の厳密な取引所時刻は取得できません。出力の価格を発注用の現在値として扱わず、売買前に証券会社で再確認してください。
- EDINET/SECの公式XBRL全銘柄財務はv1.2には未実装です。ここを曖昧にせず、v1.3の拡張対象とします。
- リアルタイム取引向けではありません。各市場の直近完了終値を使う日次スクリーナーです。
- 欠損値を推測補完しません。欠損・部分取得は `flags` と `quality_report.json` に残します。
- スコア上位は「買い」ではなく、ファンダメンタルズ精査対象です。
- テーマ判定は、金融・海運などの集中を抑えるための保守的なキーワード判定であり、公式の業種分類ではありません。
- 決算予定日の公式な日米共通ソースは未接続です。決算アラートを推測で表示せず、`daily_report.md` に未接続と明記します。

## あなたが行う作業（初回のみ）

### 1. GitHubに公開リポジトリを作成

リポジトリ名の例：`investment-quant`

このフォルダの中身をすべてアップロードしてください。保有株数・取得単価・現金残高は置かないでください。

### 2. 小規模テスト

`Actions → Daily Quant Screen → Run workflow` を開き、次のように入力します。

- `max_tickers`: `10`

成功すると `data/` に3ファイルが作られます。

- `screening_latest.csv`: ChatGPTへ渡す上位候補
- `screening_full.csv.gz`: 全銘柄の価格一次選抜結果
- `quality_report.json`: 件数、欠損率、基準日、警告
- `daily_report.md`: テーマ偏り、候補、順位変化、発注前の確認事項

### 3. 全銘柄実行

小規模テスト後、再びRun workflowを開きます。

- `max_tickers`: `0`

今回の検証環境では全銘柄処理が約30秒で完了しました。ただし実行環境や提供側の状況で変動します。

## 日常の運用

平日16:00にGitHub Actionsが更新し、`daily_report.md` が16時台に作成されます。

1. まず `daily_report.md` の「Theme distribution」を確認します。
2. 同じテーマが増えている日は、新規発注を急がず、上位化の理由を確認します。
3. 「Research candidates」のうち、順位が急上昇した銘柄だけを決算・開示確認の対象にします。
4. 証券会社の現在値、最新決算、保有銘柄との経済的な重複を確認できた場合だけ、最大1テーマ1銘柄を検討します。

## ChatGPTへの依頼文

> 最新の daily_report.md、screening_latest.csv と quality_report.json を確認してください。まずデータ基準日、対象銘柄数、欠損率、警告を監査し、監査を通過した場合だけ分析してください。同一テーマの重複を増やさず、セクター固有指標・決算特殊要因・反証・私のポートフォリオへの限界貢献で、最大5銘柄まで絞ってください。現在株価を別途取得できない場合は指値を断定しないでください。

## 主な環境変数

| 変数 | 既定値 | 意味 |
|---|---:|---|
| `MAX_TICKERS` | 0 | 0は全銘柄。テスト時は市場ごとの件数 |
| `OUTPUT_TOP_N` | 100 | 最終CSVの件数。市場数で均等配分 |
| `MIN_TURNOVER_JP` | 50000000 | 日本株の20日平均売買代金下限（円） |
| `MIN_TURNOVER_US` | 1000000 | 米国株の20日平均売買代金下限（ドル） |
| `MAX_PER_THEME` | 2 | 1市場で金融または海運を候補として表示する最大社数 |
| `RANK_ALERT_THRESHOLD` | 15 | 前回からこの順位以上上がった場合に `rank_up` と表示 |

## データ品質の停止条件

次の場合はランキングをそのまま使わないでください。

- `price_missing_rate` が10%を超える
- `data_retrieved_at_utc` が想定時刻より古い
- 片方の市場の銘柄数が極端に少ない
- `fundamental_status.missing` が急増する
- Actionsの実行が赤い×で終了する

30%超の価格欠損ではプログラム自体が停止します。10〜30%は実行結果を残しますが、分析利用は停止してください。

## このパッケージの検証結果

2026-08-17（日本時間）に実通信で全銘柄テストを実施しました。

- 公式ユニバース：9,580銘柄（日本3,706、米国5,874）
- 結合後行数：9,580（重複0）
- 価格欠損率：約9.4%
- 流動性・価格条件を通過：5,358銘柄
- スコア算出：5,352銘柄
- 最終出力：日本50＋米国50、重複0、総合スコア欠損0
- 単体テスト：2件合格
- 全処理時間：検証環境で約30秒

これは動作確認であり、翌日以降のデータ提供継続や値の正確性を保証するものではありません。
