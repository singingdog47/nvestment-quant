# 日本株 5営業日先行・恐怖／楽観メーター（試験版）

## 投資家向け表示
1. 現在の市場心理：0=極度の恐怖、100=極度の楽観。観測日時とカバレッジを必ず表示。
2. 5営業日先の心理予測：予測値、方向、予測区間、検証済み精度を表示。未検証時は「未算出」。
3. PFへの示唆：相場環境と個別銘柄・余力を別々に確認。指数単独で売買を指示しない。

## データ
ボラティリティ25%、市場の広がり25%、トレンド15%、先物10%、信用・クレジット15%、為替・海外市場10%。各入力は0〜100のリスク選好スコアに正規化してから入力する。入力値をVIXそのものと混同しないこと。欠損・鮮度・品質は入力単位で管理し、カバレッジ80%未満、VIまたはbreadth欠落の場合は現在値も出さない。

## 予測モデルの採用条件
- まず日次の時系列データと観測時刻を保存する。過去データの後付け変更や未来情報混入を禁止。
- 5営業日先の実測心理スコアの変化を予測する。指数騰落率予測とは区別。
- 時系列ウォークフォワードで、単純な現状維持予測・過去5日平均・VI単独をベースライン比較する。
- MAE、方向一致率、予測区間の実測包含率、恐怖局面での誤判定を評価する。
- 検証が終わるまで forecast_5d=null、売買トリガーには使用しない。

## 実行
`python src/leading_sentiment_meter.py input.json --output meter.json`
入力例：
```json
{
  "as_of": "2026-11-06T16:00:00+09:00",
  "signals": {
    "volatility": {"value": 15, "observed_at": "2026-11-06T15:50:00+09:00"},
    "breadth": {"value": 20, "observed_at": "2026-11-06T15:30:00+09:00"}
  }
}
```
この例の15、20は説明用の架空の正規化スコアであり、11/6の実測値ではない。欠損のため出力は INSUFFICIENT_DATA となる。

## 既存運用との分離
試験版は入力JSONを読み取り、評価結果を出すだけ。既存のPF判断、注文、定期実行、公開レポートには接続しない。統合は実データ取り込み・検証・レビュー後に別途判断する。
