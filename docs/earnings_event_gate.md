# 決算・適時開示ゲート（研究段階）

## 目的
保有銘柄の株価が動いた理由を述べる前に、直近の決算・適時開示を確認する。確認できない場合は「材料なし」と書かず「未確認」と表示する。

## 運用上の必須順序
1. 当日の非公開PFから銘柄コードを取得。公開GitHubへ銘柄別保有数量・取得価額・注文情報を保存しない。
2. 銘柄ごとに決算予定日、直近決算発表、適時開示、業績修正、配当・資本政策を一次情報と照合。
3. 取得元URL、発表日時（JST/UTCを区別）、確認日時、確認範囲を記録。
4. 直近イベントがあれば市場予想差、会社計画、利益率、セグメント、株価反応を確認。
5. イベント未確認・確認日時が古い・内容未レビューなら、株価下落の原因断定や新規売買推奨を停止。既存注文の緊急リスク管理は別途人間が判断。
6. 検証済みイベント情報を市場・PF・注文の各ゲートに渡して初めて投資判断。

## サンリオ再発防止ケース
2026-11-06 15:30 JSTに8136の2027年3月期2Q決算発表。
2026-11-09朝の株価下落を「理由不明の市場逆行」とする前にイベント確認が必須。
決算の存在だけでは下落原因は断定できない。市場予想差・利益率・会社見通しを分析する。

特にevent_status=NO_EVENT_CONFIRMEDは外部の信頼できる検証済みソースが必要。推測で渡してはならない。
